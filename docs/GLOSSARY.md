# Glossary

- **Administrator:** manages users, settings, keys, audit history, notification archives, assignments, and system operations.
- **Data Analyst:** imports and explores data, runs analyses, creates evaluations, compares models, and uses tuning evidence.
- **Maintenance Technician:** reviews assigned anomalies, submits feedback, records inspections and actions, and completes assigned orders.
- **Source type:** provenance for a measurement or device: `manual`, `sensor`, `simulated`, or `dataset`.
- **Analysis:** a persisted detector run over selected input data.
- **Evaluation:** a simulator-labelled comparison against stored ground truth.
- **Validation:** retained dataset or NASA IMS evidence. It does not imply window-level fault labels.
- **Tuning:** a development search over candidates and parameters.
- **Severity:** reviewer-facing statistical evidence, not a diagnosis.
