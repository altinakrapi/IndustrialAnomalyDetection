# Administrator guide

## Manage users and roles

Open **Users**, select a user, and use the available role or account controls. Only an Administrator can perform this task.

## Configure the system

Open **Settings** for application configuration.

## Manage device API keys

Open **Devices**, select a device, and create or revoke keys. Save a newly issued plaintext key securely.

## Assign responsibility

In the selected device, choose the responsible recorder and maintenance technician. Assignment controls belong to the Administrator role.

## Review audit and notifications

Open **Audit** for recorded actions. Open **Notifications** for archive, restore, and related Administrator operations.

## Permission summary

The Administrator has the broadest access: users and roles, settings, device keys, notification archive and restore, audit, assignments, analyst workflows, and reports. See [PERMISSIONS.md](../PERMISSIONS.md).
